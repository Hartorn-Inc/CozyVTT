# Independent clone under Hartorn-Inc, not a GitHub fork

Hartorn-Inc/CozyVTT is a full-history copy of CheekyChinchilla/CozyVTT, not a GitHub fork. Work lands on `origin` (this repo); `upstream` stays the original for pulling updates. We picked an independent clone so the org owns default branch, protection, CI, and visibility without fork constraints.
